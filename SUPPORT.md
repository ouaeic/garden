# Getting help

Start with the [installation and connection guide](README.md#install).
For home servers, local models and same-network access, see
[local models](docs/LOCAL_MODELS.md) and [direct connections](docs/relay.md).

- Ask setup questions or share beta feedback in [Discussions](https://github.com/ouaeic/garden/discussions).
- Report a reproducible problem using the [bug form](https://github.com/ouaeic/garden/issues/new?template=bug_report.yml).
- Suggest a smoother workflow using the [feature form](https://github.com/ouaeic/garden/issues/new?template=feature_request.yml).
- Report vulnerabilities [privately](https://github.com/ouaeic/garden/security/advisories/new).

Include your Garden version or commit, client and server operating systems, browser, and steps
using synthetic data. `sudo garden doctor` checks server health; inspect its output before sharing
and redact identifying addresses or other private details. Never post credentials, recovery
material, cookies, private prompts or full unredacted diagnostics.

Garden is self-hosted. Your account, model access and files belong to your own server;
repository maintainers cannot reset its password or retrieve its data. Follow the
[password recovery instructions](README.md#sign-in-with-a-password) when access is lost.

Beta clients are direct downloads. Free desktop builds may show operating-system trust prompts;
iOS device distribution requires Apple provisioning. Android closed-app push is not included.
See [beta clients](docs/BETA_CLIENTS.md) for platform and signing details.
