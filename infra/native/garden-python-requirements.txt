# The only Python libraries garden pins itself. Everything else the document skills use -
# python-docx, openpyxl, pandas, matplotlib, Pillow, lxml, XlsxWriter - is packaged by Debian and
# Ubuntu, and the distribution's own pin is the better pin: it is signed, mirrored, and security
# supported. What is listed here is what apt cannot give a vetted procedure.
#
# pypdf is here because Debian 12 ships 3.4.1 and Ubuntu 24.04 ships 4.0.2, and the AcroForm
# writer API changed between them. A skill that says "call PdfWriter(clone_from=...)" is either
# right or wrong depending on which release the box booted, and a procedure that is sometimes
# right is the thing this library exists to stop.
#
# Installed with --require-hashes --no-deps --only-binary=:all:, so pip takes only the listed
# wheels and nothing else, and a compromised mirror cannot substitute a different build.
# Licences: pypdf is BSD-3-Clause, typing_extensions is PSF-2.0. Both are compatible with
# distributing garden under AGPL-3.0-or-later.
