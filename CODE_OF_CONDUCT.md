# Code of conduct

Garden welcomes contributions and feedback from people with different backgrounds and levels of
experience. Treat others respectfully, critique ideas with evidence, and help new contributors
understand the project.

Harassment, threats, discriminatory abuse, sexual harassment, and publishing another person's
private information are unacceptable. These expectations apply to issues, discussions, pull
requests, reviews, and other project spaces.

For sensitive conduct concerns, use GitHub's **Report abuse** action on the relevant content.
Nonsensitive concerns about moderation can be raised with maintainers in a repository discussion.
Do not post private identifying details in public reports.

Maintainers may edit or remove inappropriate content, limit participation, or block repeated or
serious misconduct. Decisions should be proportionate and protect participants' privacy.
