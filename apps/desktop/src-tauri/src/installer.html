Install on your server

The garden app connects directly over SSH, verifies the server identity, installs from the fixed public source, and imports the one-time connection ticket. SSH secrets stay in this local page’s memory and are never stored or relayed.

This is not the fingerprint of your login key. For an ED25519 host key, open the provider’s browser console and run sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256. Compare both the algorithm and SHA256 value above. This prevents a lookalike server from receiving your credentials.

Use a fresh supported Ubuntu or Debian server. The login must be root or have passwordless sudo. Garden never changes the SSH service.
